The user authorized correction of the v3.3 factual-review issues. V4 is a separate implementation and replay runner. The frozen Phase-1D protocol, v1/v2/v3 code, 718-record sample in 297 cells, prior AUTOMATED reviews, original three human decisions and five newer human excerpt answers remain unchanged.

## Corrections and boundaries

Heading-only and cross-reference-only spin mentions remain context. Funds-from-operations definitions and relative financial descriptions do not independently establish a separation plan. Genuine transaction agreements, Board approvals, conditional plans and pro-rata distribution descriptions remain candidates for review.

Canonical merger-proxy identity takes precedence over a shareholder salutation. Explicit combined proxy/prospectus-information statements have their own document role. Supporting contracts and correspondence retain separate roles.

An unambiguous program reference or explicit maximum total repurchase cap may attach facts from up to three following sentences within the same paragraph. Every added fact has a separate source citation. Paragraph boundaries, different programs and preferred-stock references stop transfer. Contradicting amounts are retained with a conflict flag. A share-price ceiling does not become approved capacity, and a stated possible duration does not become an exact expiration date.

A printed city/date dateline with explicit today-announced language can establish a reported announcement-date field. It does not establish the Board approval date or verified public dissemination time. Dated multi-actor announcements and explicit undated previously-announced wording retain recap flags.

Another repurchase without an explicit program relationship remains AMBIGUOUS. Explicit additional amounts remain directly sourced facts. Amount-scale normalization is used only for documentary match suggestions. Subtype disagreement is flagged; matching passages are never automatically merged into a final economic action.

## Reproduction and integrity

Use the existing Python environment from the standalone repository root, with an unused run ID:

```powershell
python -X utf8 -I -S -B tools/corporate_events/parser_development_v4.py --run-id offline-development-v4-003
```

The runner verifies registered file hashes, exact parser/policy identities, predecessor extensions, the original sample and review identities, cached source bytes, evidence spans and before/after baseline hashes. It installs the existing SEC-only filesystem/import firewall and an explicit no-network audit hook. Each run saves its code, input identities, source results, record comparisons and hash manifest. Existing run directories cannot be overwritten.

All replay inputs are existing cached sources. No acquisitions, sample replacements, schema-authority expansion, market-data access or outcome calculations are permitted.

All proposals remain pending and withheld from research. Historical ownership semantics, comparable prior dividend baselines, transaction-parent/action identity, earliest disclosure and public dissemination require further evidence. Final QA, full extraction and Phase 3 remain closed.
